# 01 — 记忆采集与授权

## 信号来源

- 显式陈述：「以后推荐酒店时优先安静」
- 显式操作：保存、置顶、删除、纠正、选择“不感兴趣”
- 隐式行为：点击、停留、复访、购买、工具执行结果
- 导入上下文：邮件、日历、文件、浏览器或其他连接器

## 产品策略

按写入风险分级：

1. **会话状态**：可自动维护，默认随会话过期。
2. **任务状态**：在用户创建/继续项目时保存，并提供结束或归档入口。
3. **长期偏好**：明确陈述可直接提示后保存；隐式推断需多证据并允许确认。
4. **敏感属性**：默认不从行为推断；确需使用时采用单独授权和最小化存储。

## Consent receipt

保存授权本身也应结构化：

```yaml
purpose: personalize_travel_search
scope: domain:travel
data_categories: [preference, companion_constraints]
retention: 180d
granted_at: ...
revocable: true
```

## 失败模式

- 将一次性要求误写为永久偏好
- 用点击直接推断喜欢，忽略位置偏差和探索行为
- 连接器授权范围过大
- 用户关闭 memory 后仍使用派生画像
