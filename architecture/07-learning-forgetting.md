# 07 — 反馈学习、冲突、衰减与遗忘

## Feedback hierarchy

可信度通常为：

```text
用户明确纠正/保存
  > 完成购买或执行任务
  > 重复选择
  > 单次点击/停留
  > 助手推断
```

## 在线学习边界

- 单次行为先进入 episode，不直接改长期 profile
- 用多次、跨任务一致性判断稳定偏好
- 对负反馈区分「不喜欢这个候选」与「不喜欢这类候选」
- 保留探索，避免系统自我强化：系统先推荐 A → 用户只能点 A → 更确信用户爱 A

## 冲突处理

新旧记忆冲突时：

1. 当前显式指令覆盖历史项。
2. 同 scope 内优先更近、已确认的信息。
3. 不同 scope 可共存，如工作旅行与家庭旅行。
4. 影响重大时展示冲突并请求确认。

## 衰减

可按 memory 类型使用不同半衰期：

- 临时兴趣：短
- 项目状态：任务完成后快速衰减
- 交互格式偏好：中等
- 用户明确保存的稳定偏好：长，但仍可复核

## 遗忘

- TTL 自动过期
- 用户主动删除
- 任务结束归档
- 低置信长期未使用降权
- 法规或账号删除触发完整删除传播

遗忘是核心产品能力，不是后台清理任务。
