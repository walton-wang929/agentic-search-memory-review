# Contributing

## Add or update a company

1. Copy `templates/company-review.md`.
2. Separate **shipped**, **experiment**, **public technical signal**, **inference**, and **unknown**.
3. Prefer first-party product/help/developer sources.
4. Add verification date and URLs.
5. Do not infer private cross-product data sharing from common corporate ownership.

## Review standard

- A chat transcript is not automatically long-term memory.
- A large context window is not persistent memory.
- A recommendation profile is not automatically user-visible Agent memory.
- Infrastructure capability does not prove a front-end product uses it.
- Turning a feature off and deleting its stored data are distinct operations.

## Scorecard

Use 0–3:

- 0: no public evidence
- 1: partial or inferred
- 2: usable product capability
- 3: mature, differentiated, and user-controllable

Keep unresolved claims marked as unknown instead of filling gaps with certainty.
