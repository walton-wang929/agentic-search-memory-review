# 其他海外玩家

## Perplexity

- 核心优势是 retrieval-first、引用和快速研究，而非公开的长期个人 memory。
- Spaces / Collections / Threads 可提供中期主题与任务上下文。
- 个性化可能影响回答和 source selection，但 memory 的抽取、查看与遗忘机制不如 ChatGPT/Claude 公开清晰。
- Review 重点：搜索质量强，长期用户模型与控制面需实测。

## Microsoft Copilot

- Microsoft Graph、Outlook、Teams、OneDrive 与工作画像构成强中期/长期企业上下文。
- Copilot Memory / personalization 与企业连接器可以改善搜索和行动，但必须受 tenant、RBAC、sensitivity label 和 DLP 约束。
- 对 Agentic Search 的意义：企业 memory 不是单一用户 profile，而是权限实时变化的组织知识图。

## Apple Intelligence / Siri

- 个人语义索引、设备端上下文和 Private Cloud Compute 代表隐私优先路线。
- 对 Search 的潜力在于跨邮件、消息、照片和日历做按需检索，同时尽量减少长期集中画像。

## 横向判断

| 玩家 | 最强 memory 资产 | 主要短板 |
|---|---|---|
| Perplexity | 搜索线程与主题空间 | 长期 memory 产品控制较弱/不透明 |
| Microsoft | 企业 Graph 与工作流 | 权限与组织隔离复杂 |
| Apple | 设备端个人上下文 | 开放 Web Agent 闭环仍有限 |

具体能力变化快，纳入评分前应以最新官方文档和账号实测核验。
