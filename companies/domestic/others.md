# 百度及其他国内玩家

## 百度

- 百度搜索拥有长期搜索画像、位置、内容与广告推荐系统；文心/AI 搜可在此基础上做个性化搜索。
- 公开信息更容易证明传统推荐画像存在，较难证明生成式 Agent 有独立、用户可管理的长期 memory。
- Review 时应区分：搜索历史个性化、广告画像、文心对话历史、Agent memory。

## Kimi

- 长上下文、文件和研究任务适合短/中期 memory。
- 主题/项目、历史聊天检索与文件知识库可形成中期工作空间。
- 长期偏好抽取、memory 管理和对 Search ranking 的作用需按最新版本实测。

## DeepSeek

- 更接近基础模型与推理入口，公开产品强调模型能力和会话。
- 它可作为其他产品的推理模型，但最终用户 memory 通常由接入方的应用层实现。
- Review 时不要把模型 context window 误认为持久化 memory。

## 国内共同趋势

1. 从历史聊天进化到结构化 memory。
2. 从通用偏好进化到购物、出行、内容等 domain memory。
3. 从回答个性化进化到工具参数、交易和主动服务。
4. 用户控制、跨 App 授权和删除传播仍普遍弱于能力建设速度。
