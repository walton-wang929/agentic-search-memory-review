# 小红书：点点 / 问一问 / 搜索

## 产品机制

### 公开可见

- 点点基于小红书站内笔记做对话式生活决策搜索，支持多轮追问，并展示相关原文与互动数据。
- 2026 年 PC 端报道显示，用户可把自己点赞或收藏过的笔记导入对话作为上下文，使旅行、装修、穿搭等回答更贴合既有审美和兴趣。
- 小红书拥有成熟的搜索、推荐、收藏和兴趣图谱，这是个性化 Agentic Search 的关键资产。

### 未充分公开

- 是否存在类似 ChatGPT Saved Memories 的独立长期记忆管理页。
- 点赞/收藏、搜索和交易行为是否自动形成 Agent 可读取的长期 profile。
- 点点、问一问与主站推荐画像之间的数据边界和授权策略。

## Memory 分层映射

| 层级 | 可能机制 | 证据等级 |
|---|---|---|
| 短期 | 多轮对话中保持本轮约束 | 产品可见 |
| 中期 | 用户主动导入点赞/收藏笔记，形成任务上下文 | 媒体/产品报道 |
| 长期 | 主站兴趣、审美、搜索与消费画像 | 平台能力存在；Agent 如何使用未知 |

## Agentic Search 注入点

- **Retrieval**：优先召回与用户收藏、兴趣相近的 UGC。
- **Ranking**：结合社交证明、内容质量和审美偏好重排。
- **Synthesis**：将分散笔记综合为旅行、装修、穿搭等结构化方案。
- **Action**：可进一步连接商品、本地生活和收藏；闭环深度仍需实测。

## 技术实现判断

**合理推断：**

- 推荐系统 user embedding + Search query embedding + UGC 内容图谱是天然底座。
- 用户主动导入收藏是一种低风险、强 consent 的中期 memory 方案，比默认读取全部行为更可控。
- 若要做长期 memory，应把「兴趣推荐画像」和「用户确认的 Agent memory」分开，避免把一次浏览当成稳定偏好。

## 优势

- 生活决策 UGC 密度高，偏好信号比通用 Web 更细。
- 收藏、点赞与创作内容天然携带审美和经验。
- 推荐系统已有持续兴趣建模能力。

## 风险与开放问题

- 商业内容和种草行为可能污染记忆与排序。
- 过度依赖历史审美会抑制探索。
- 用户删除收藏后，派生 profile 是否同步更新未知。
